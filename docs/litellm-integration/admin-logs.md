# Страница Logs: логи запросов

Страница `/ui/logs` — таблица с деталями каждого API-запроса к LiteLLM.

## Что показывает

- request_id, время начала/конца
- модель, провайдер, API-ключ
- расход ($), токены (prompt/completion)
- статус (успех/ошибка)
- IP клиента, user-agent
- messages и response (опционально)

## Фильтры

- По дате (start_date / end_date)
- По модели
- По API-ключу
- По пользователю
- По команде
- По статусу

## Источник данных

Таблица `LiteLLM_SpendLogs` — сырые логи каждого запроса. Каждая строка = один API-запрос.

Данные агрегируются в daily-таблицы для графиков Usage, но на странице Logs отображаются сырые записи.

## Эндпоинты

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| GET | `/spend/logs/ui` | Логи для UI (пагинация) |
| GET | `/spend/logs/ui/{request_id}` | Детали конкретного запроса |
| GET | `/spend/logs/v2` | Логи v2 API |
| GET | `/spend/logs` | Логи (legacy) |
| GET | `/spend/logs/session/ui` | Логи по session_id |
