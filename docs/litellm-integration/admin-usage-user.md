# User Usage

Раздел «User Usage» — аналитика расходов по отдельным пользователям. Доступен администратору (`adminOnly`).

## Что показывает

- Расход по каждому пользователю за период
- Breakdown по моделям, провайдерам, ключам внутри каждого пользователя
- Токены и число запросов
- Список пользователей

## Источник данных

Таблица `LiteLLM_DailyUserSpend` через `get_daily_activity()` — агрегируется по `user_id + date + api_key + model`.

## Эндпоинты

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| GET | `/user/daily/activity` | Daily-активность по пользователям |
| GET | `/user/daily/activity/aggregated` | Агрегированная активность |
| GET | `/user/list` | Список пользователей |
