# Customer Usage

Раздел «Customer Usage» — аналитика расходов по клиентским аккаунтам. Доступен только администратору (`adminOnly`).

## Что показывает

- Расход по клиентам (end users) за период
- Breakdown по моделям, провайдерам, ключам внутри каждого клиента
- Токены и число запросов

## Источник данных

Таблица `LiteLLM_DailyEndUserSpend` через `get_daily_activity()` — агрегируется по `end_user + date + api_key + model`.

## Эндпоинт

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| GET | `/customer/daily/activity` | Daily-активность по клиентам |
