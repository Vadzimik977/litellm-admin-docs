# Your Usage

Раздел «Your Usage» — аналитика собственной учётки. В коде это `value:"my-usage"`.

Для обычных пользователей (`INTERNAL_USER`) это главный раздел мониторинга — они видят сюда свою собственную статистику. Для администратора именно здесь показывается их личная активность (отдельно от глобальной).

## Что показывает

- Собственный расход и число запросов
- Токены (prompt/completion)
- Breakdown по моделям, провайдерам, ключам
- Собственные теги

## Фильтрация

Данные всегда ограничены текущим пользователем (`user_id`). Не-админ не может посмотреть чужую статистику — при запросе чужого `user_id` возвращается 403.

## Эндпоинты

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| GET | `/user/daily/activity` | Daily-активность текущего пользователя |
| GET | `/user/daily/activity/aggregated` | Агрегированная активность (SQL GROUPING SETS) |
| GET | `/tag/user-agent/per-user-analytics` | Пер-пользовательская аналитика |
