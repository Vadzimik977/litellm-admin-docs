# Страница API Keys: управление ключами

Страница `/ui/api-keys` — управление виртуальными API-ключами для доступа к LiteLLM.

## Что показывает

- Список всех ключей с фильтрацией по команде, пользователю, статусу
- Информация о каждом ключе: расход, бюджет, срок действия, модели
- Возможность создавать, обновлять, блокировать, удалять ключи

## Структура ключа

Ключ хранится в таблице `LiteLLM_VerificationToken`:

| Поле | Описание |
| ---- | -------- |
| `token` | SHA-256 хэш от текстового ключа (никогда не хранится в открытом виде) |
| `key_name` | Имя ключа (alias) |
| `key_type` | Тип: `virtual_key` или `service_account` |
| `user_id` | Владелец |
| `team_id` | Привязка к команде |
| `organization_id` | Привязка к организации |
| `models` | Список допустимых моделей |
| `max_budget` | Лимит расхода |
| `budget_duration` | Период сброса бюджета |
| `expires` | Дата истечения |
| `blocked` | Заблокирован ли |
| `tpm_limit` | Лимит токенов в минуту |
| `rpm_limit` | Лимит запросов в минуту |
| `max_parallel_requests` | Лимит параллельных запросов |
| `metadata` | Произвольные метаданные (JSON) |
| `guardrails` | Привязанные guardrails |
| `permissions` | Права доступа |
| `object_permission` | Ограничения доступа к объектам |
| `auto_rotate` | Автоматическая ротация |
| `rotation_interval` | Интервал ротации |

## Как создаётся ключ

1. Генерируется токен: `sk-{secrets.token_urlsafe(...)}`
2. Токен хэшируется через SHA-256
3. Проверяется уникальность хэша
4. Запись создаётся в `LiteLLM_VerificationToken`
5. Текстовый ключ возвращается в ответе **только один раз**

## Ротация ключа

При `auto_rotate = true` и `rotation_interval` (например `"30d"`):
- Старый ключ аннулируется
- Создаётся новый токен
- Новый ключ возвращается в ответе

## Эндпоинты

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| POST | `/key/generate` | Создание ключа |
| POST | `/key/service-account/generate` | Сервисный ключ |
| POST | `/key/update` | Обновление |
| POST | `/key/bulk_update` | Массовое обновление |
| POST | `/key/delete` | Удаление |
| GET | `/key/info` | Информация |
| POST | `/key/{key}/regenerate` | Ротация |
| POST | `/key/{key}/reset_spend` | Сброс расхода |
| GET | `/key/list` | Список |
| POST | `/key/block` | Блокировка |
| POST | `/key/unblock` | Разблокировка |
| GET | `/key/health` | Проверка здоровья |
