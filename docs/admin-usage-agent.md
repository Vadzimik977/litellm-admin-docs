# Agent Usage (A2A)

Раздел «Agent Usage» — аналитика расходов по AI-агентам (A2A). Доступен администратору (`adminOnly`).

## Что показывает

- Расход по AI-агентам за период
- Breakdown по моделям, провайдерам, ключам внутри каждого агента
- Токены и число запросов

## Источник данных

Таблица `LiteLLM_DailyAgentSpend` через `get_daily_activity()` — агрегируется по `agent_id + date + api_key + model`.

## Эндпоинт

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| GET | `/agent/daily/activity` | Daily-активность по агентам |
