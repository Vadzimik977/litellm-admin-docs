# LiteLLM Admin Panel

Документация по встроенному веб-интерфейсу админ-панели LiteLLM (`/ui`).

## Что здесь описано

- **Интеграция с БД LiteLLM** — подключение к PostgreSQL, модели из базы, идентификация пользователя.
- **Ценообразование моделей** — файлы цен, тарифные профили организаций, расчёт стоимости.
- **LiteLLM Admin Panel** — все разделы панели: пользователи, команды, организации, ключи, модели, бюджеты, логи, настройки, расходы и аналитика.

## Быстрый старт

1. [Интеграция с БД LiteLLM](litellm-integration/litellm_db.md) — настройка подключения.
2. [LiteLLM Admin Panel](litellm-integration/litellm_admin.md) — обзор разделов панели.
3. [Ценообразование моделей](litellm-integration/pricing.md) — конфигурация цен.
