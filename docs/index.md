# LiteLLM Admin Panel

Документация по встроенному веб-интерфейсу админ-панели LiteLLM (`/ui`).

## Разделы панели

- **Overview** — обзор, технологический стек, вход и роли.
- **Users** — внутренние пользователи и их бюджеты.
- **Teams** — команды и общие бюджеты.
- **Organizations** — организации верхнего уровня.
- **API Keys** — виртуальные ключи доступа.
- **Models** — модели, провайдеры и ценообразование.
- **Budgets** — лимиты расходов.
- **Logs** — логи запросов.
- **Settings** — настройки UI, SSO, дефолтные параметры.
- **Usage** — расходы и аналитика (Global, Team, Tag, User и др.).
- **Activity** — активность по моделям, ключам, MCP-серверам, командам, пользователям.
