# Страница Budgets: управление бюджетами

Страница `/ui/budgets` — создание и управление бюджетами, привязываемыми к ключам, пользователям, командам, организациям.

## Структура бюджета

Запись в `LiteLLM_BudgetTable`:

| Поле | Описание |
| ---- | -------- |
| `max_budget` | Лимит расхода (float, >= 0) |
| `soft_budget` | Мягкий лимит (alert без блокировки) |
| `budget_duration` | Период сброса (`"30d"`, `"1h"`, `"30m"`) |
| `budget_reset_at` | Автоматически вычисляется |
| `max_parallel_requests` | Лимит параллельных запросов |
| `tpm_limit` | Лимит токенов в минуту |
| `rpm_limit` | Лимит запросов в минуту |
| `model_max_budget` | Бюджет по моделям: `{"gpt-4o": {"max_budget": 100.0, "budget_duration": "1d"}}` |

## Порядок проверки

При обработке запроса: бюджет ключа → бюджет пользователя → бюджет команды → бюджет организации.

- `max_budget = 0` — полный запрет расхода
- `NULL` — безлимит

## Эндпоинты

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| POST | `/budget/new` | Создание |
| POST | `/budget/update` | Обновление |
| POST | `/budget/info` | Информация |
| GET | `/budget/settings` | Настройки (для UI) |
| GET | `/budget/list` | Список |
| POST | `/budget/delete` | Удаление (только PROXY_ADMIN) |
