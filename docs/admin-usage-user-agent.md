# User Agent Activity

Раздел «User Agent Activity» — детальные логи активности по User-Agent. Доступен администратору.

## Что показывает

- Сводки по каждому User-Agent
- Per-user аналитика по User-Agent
- Расход, токены, запросы

## Эндпоинты

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| GET | `/tag/summary` | Сводка по User-Agent |
| GET | `/tag/user-agent/per-user-analytics` | Пер-пользовательская аналитика по User-Agent |
